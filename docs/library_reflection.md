# Reflection

## Challenges Faced

One challenge during this assignment was deciding the correct level of detail for the diagrams. Adding too many states and actions made the diagrams difficult to read, while too little detail reduced clarity and completeness.

Another challenge was ensuring alignment between functional requirements, user stories, and workflow diagrams from previous assignments. Maintaining consistency across all assignments required careful planning.

## State Diagrams vs Activity Diagrams

State transition diagrams focus on the lifecycle and behavior of specific system objects such as books, loans, and memberships.

Activity diagrams focus on workflows and processes, showing how users and the system interact to complete tasks such as borrowing books or paying fines.

## Lessons Learned

This assignment improved understanding of UML modeling, workflow design, and system behavior representation.

I also learned how state modeling and activity workflow modeling support software analysis and system design before implementation.

Using Mermaid diagrams and GitHub improved documentation and version control management skills.
